# To questionnaire

Grill the send, not the subject: establish who receives the questionnaire and what the user needs back. Reuse context already supplied. Ask about missing recipient context or desired decisions, not facts that only the recipient can know.

Write a self-contained discovery questionnaire: purpose, enough context to answer, instructions, and prioritized questions with answer space. Group by theme when useful. Each question should target one fact or decision; add why it matters when easily misunderstood.

Allow partial answers and uncertainty. Include a deadline or effort estimate only when supplied or clearly marked as a suggestion. End with space for missing concerns.

Save to the requested location, otherwise a new to-questionnaire-<topic>.md in the current workspace without overwriting existing work. Verify that the questions cover the user's information gaps and report the path. Drafting does not send it to the recipient.
