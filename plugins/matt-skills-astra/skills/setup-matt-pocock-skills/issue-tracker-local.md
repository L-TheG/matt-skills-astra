# Issue tracker: local Markdown

Reuse the project's existing local-ticket convention. If none exists and local files are requested, a compact layout is:

- .scratch/<effort>/spec.md for the specification.
- .scratch/<effort>/issues/NN-<topic>.md for individual tickets.
- .scratch/<effort>/map.md for Wayfinder notes, decisions, and uncertainty when needed.

Tickets state type, status, relevant blockers, acceptance criteria, and evidence of resolution. The frontier contains unclaimed work with satisfied prerequisites. A canceled item is not automatically satisfied.

Create or update only the requested records. Preserve user edits and historical decisions; verify links. Local drafts do not require remote labels or tracker credentials.
