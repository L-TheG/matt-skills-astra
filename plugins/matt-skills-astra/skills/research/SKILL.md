# Research

Resolve the stated question from relevant local code, documentation, experiments, or primary external sources. Retrieve current information where versions or behavior may have changed.

Separate observations, source claims, and your inference. Compare competing explanations when they matter; stop once evidence is sufficient for the user's decision, not after exhausting every adjacent topic.

Return the answer with source paths or links, important caveats, and any unresolved gap. Create a separate research artifact only when requested or useful for a durable handoff. Delegate a bounded investigation only when that improves the work and delegation is available and allowed; a background agent is not required for ordinary research.
