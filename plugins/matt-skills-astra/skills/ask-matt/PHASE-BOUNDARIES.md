# Continuation and handoff

Continue in the current task while the necessary context is available and work remains in scope. A workflow phase ending is not a reason to pause, clear context, or compact.

Use the host's context-management mechanisms when needed; do not assume a fixed "smart zone", a token threshold, or Claude slash commands apply to Astra.

For a requested handoff, preserve objective, settled decisions and reasons, source pointers, current changes, verification, unresolved questions, and the next useful action. Distinguish observations from assumptions. Creating a fresh task, moving a checkout, or starting a background agent requires the corresponding user intent and an available host capability.
