# Grilling

Treat the design as a tree of decisions: answers unlock dependent questions. Focus on branches that can materially change the user's objective, not every imaginable detail.

Ask a manageable round of independent questions, each with a recommendation and brief trade-off. Follow the host's question-tool limits. A question depending on an unanswered choice belongs in a later round.

Find discoverable facts from the environment yourself. Separate evidence from decisions that belong to the user. Delegation is optional when available and permitted; a lookup need not become a subagent task.

Use concrete scenarios and counterexamples to expose ambiguous terms, missing constraints, and weak assumptions. Reuse answers already given. Stop when the consequential uncertainty for this request is resolved, or the user asks to proceed or stop.

Summarize settled decisions and remaining assumptions. Interviewing does not itself authorize implementation. An explicit request to proceed can authorize the next scoped action without a redundant confirmation round.
