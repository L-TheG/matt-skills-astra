# Matt Skills Astra

A personal fork of [Matt Pocock's skills](https://github.com/mattpocock/skills), adapted for GPT-6 Astra and distributed as a managed Codex plugin. Maintained by [L-TheG](https://github.com/L-TheG); not an official Matt Pocock or OpenAI release.

## Install as a plugin

In Codex's plugin UI, add this GitHub marketplace and install **Matt Skills Astra**. With the Codex CLI:

```sh
codex plugin marketplace add L-TheG/matt-skills-astra --ref main
codex plugin add matt-skills-astra@matt-skills-astra
```

Start a new task after installation if the current task has already loaded its skill catalog. The plugin works across projects on the host where it is installed. It does not require manual skill copies, symlinks, MCP credentials, or hooks.

To refresh the Git-backed marketplace:

```sh
codex plugin marketplace upgrade matt-skills-astra
codex plugin add matt-skills-astra@matt-skills-astra
```

Use the app's plugin update action when offered. Edited releases need a new plugin version. Never modify the installed cache.

This repository supplies a Codex-compatible plugin marketplace. A local Codex installation does not by itself publish a plugin to ChatGPT's public directory or another workspace. Distribution there requires the applicable workspace import or directory submission.

## Included skills

The original promoted selection is retained: 18 [engineering skills](skills/engineering/README.md) and 7 [productivity skills](skills/productivity/README.md). Existing explicit-only and automatic invocation choices are preserved. Try ask-matt to choose a workflow, or select a specific skill.

The [misc](skills/misc/README.md) and [in-progress](skills/in-progress/README.md) buckets remain source-only. They are not silently activated.

## What changed for Astra

Shorter, more discriminating descriptions; outcome-oriented instructions; fewer artificial handoffs and setup gates; proportional tests; optional delegation; host-aware tools; and scoped external writes. Matt's interviews, deep-module thinking, domain modeling, and behavioral tests remain.

See [adaptation and maintenance notes](docs/ASTRA.md). The bucketed skills are the source of truth; the installed payload is generated by:

```sh
bun scripts/build-codex-plugin.mjs
bun scripts/build-codex-plugin.mjs --check
bun test scripts/build-codex-plugin.test.mjs
```

[upstream.json](upstream.json) records the integrated upstream commit. Upstream monitoring reports relevant changes for review; it does not merge them automatically.
